# food-relief-qr-distribution-system
A Tempo-powered QR-based humanitarian system for transparent food relief distribution.
🍚 Food Relief QR Distribution System
Built for the Tempo Hackathon
A simple, transparent and secure food-aid distribution system powered by QR codes and Tempo stablecoin payments.
⭐ Problem
Traditional food relief systems suffer from:
corruption
long queues
lost vouchers
unfair distribution
no transparency
⭐ Solution
Give each beneficiary a unique QR card.
When scanned:
they receive food credits (stablecoins on Tempo)
they redeem food at local partnered shops
shops get paid instantly via Tempo
🧩 Features
Beneficiary registration
QR code identity
Instant stablecoin food credits
Merchant redemption app
Real-time reporting dashboard
Fraud-proof distribution
🛠 Project Structure
mobile/ → QR scanner app
merchant/ → shop app
smart-contract/ → Tempo food credit token
docs/ → diagrams & planning
🌍 Impact
This system helps:
poor communities get food faster
NGOs distribute fairly
donors track transparency
local shops support relief efforts
